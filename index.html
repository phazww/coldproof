How it works

  • The rules for 28 countries come from the text of each law or the regulator's own guidance, checked between 10 and 14 October 2026. Every verdict links to its source.
  • The model is open-weight and runs on your own graphics card through WebGPU. The first check downloads it once, then it is cached. There is no server and no API key.
  • The model has one job: it reads your draft and reports what it contains, quoting the exact words it found. The page then checks that each quote really is in your text. If the model says yes but cannot point to the words, that counts as missing.
  • The law is not left to the model. Which elements are required comes from the checked rules, and the lines added to the fixed version are fixed wording in 13 languages, written in advance and not generated when you run a check. I do not speak all 13, so corrections are welcome.
  • Where a country requires consent before the first email, the page says so and does not offer a rewrite. No wording fixes that.
  • Both models were run on 30 test drafts in 13 languages with known answers. Gemma got all 30 right, Qwen 26. The drafts, results and a way to run them yourself are in TESTS.md.
  • This is a research tool, not legal advice. Data protection law applies separately whenever an address identifies a person.
